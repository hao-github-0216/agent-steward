# 專案管家 App 使用說明與支援

[English](support.en.md)

專案管家（Agent Steward）把你電腦上各個 AI agent 的工作整理成一個看板：提案、進行中、卡住、完成。手機 App 讓你不在電腦前也能看進度、核准工作、問管家問題、看程式碼，有事情時收到通知。

## 開始使用

1. **在電腦上裝好專案管家**：照 [README](../README.md) 的一行指令或桌面 App 安裝。App 本身不含管家，一定要先有一台電腦在跑。
2. **讓手機連得到電腦**：建議電腦和手機都裝 [Tailscale](https://tailscale.com/)，登入同一個帳號。在電腦的管家打開「設定 → 存取」，開啟 Tailscale 存取，就會看到一個 `https://你的電腦.xxxx.ts.net:8793/` 的網址。
3. **在 App 填入這個網址**。透過 Tailscale 連線時，管家會自動認得你；用其他方式連線時，要輸入管家的管理密碼。
4. **允許通知**（選用）：有新提案、工作卡卡住、工作完成時會通知你，內容端對端加密，見[隱私說明](privacy.md)。

只想先看看長什麼樣子的話，在填網址的畫面按「先看示範」，會用範例資料展示各個畫面，不需要電腦。

## 常見問題

**顯示「連不上專案管家：A server with the specified hostname could not be found」**
手機查不到 `ts.net` 網址。打開手機上的 Tailscale App，確認已連線，並在設定裡打開「Use Tailscale DNS」，然後把 Tailscale 關掉再打開。用 Safari 打開同一個網址測試，看得到管家的網頁就代表好了。

**顯示連不上，但網址是對的**
確認電腦開著、沒有睡眠，而且管家在執行（電腦上打開 `http://127.0.0.1:8791` 看得到看板）。

**沒有收到通知**
- 在手機的「設定 → 通知」確認這個 App 的通知是開的。
- 在電腦的管家「設定 → 推播」確認推播中繼網址不是空白，並按「送測試推播到手機」。
- 剛更新 App 或剛換管家時，把 App 完全關掉再打開一次，讓它重新登記。

**通知只顯示「專案管家：有新通知」**
手機解不開這則通知，通常是換過手機或重裝過 App。把 App 完全關掉再打開，它會產生新的金鑰並重新登記。

## 回報問題

請到 [GitHub Issues](https://github.com/hao-github-0216/agent-steward/issues) 提出，寫下手機型號、系統版本、App 版本（App 的「設定」最下面）和看到的訊息。請不要在 issue 裡貼你的管家網址、密碼或專案內容。
